# OmniFetch Visual DNA & Design Decisions

## 1. Design Read

- **载体模式**：`Operate`（高频桌面工具，用户每日反复粘贴链接、监控传输与定位本地文件）
- **题材与材料**：多流并发媒体采集器（DASH 双轨合流、Range 分片并发、实时吞吐遥测）——取法专业光学监视器与广播级信号传输设备（冷矿物灰 + 精密光学青）
- **原型**：`C. 精工工具（Precision Instrument）` + Apple 原生触感物理阻尼
- **唯一视觉锚点**：下载队列中的「活体吞吐进度轨道与等宽遥测读数」（Live Throughput Track & Tabular Telemetry）；其余导航、侧栏、已完成历史全部退至冷静中性层

## 2. 两阶类目反射与拒绝清单

- **拒绝默认套路**：
  1. 拒绝紫蓝霓虹 / 暗黑发光下载器套路（OKLCH 270–330° 禁区）
  2. 拒绝暖奶油 `#F4F1EA` + 赤陶 `#D97757` 默认“高级感”三件套
  3. 拒绝旧版 `ink` 炭黑 + 亮橙图标（无品牌材质辨识度且与浅深双模系统割裂）
  4. 拒绝多色彩虹状态徽章（绿/橙/蓝/红混杂），严格遵守单屏 ≤ 6 色
- **题材归属理由**：视频/图集下载器界面内存在大量高饱和平台封面图（B 站、小红书、YouTube），冷矿物中性底（色相 ~215°）确保缩略图零偏色；单一光学青（Light `#0B6E77` / Dark `#3BBCC7`）只赋予主动作与活跃流，故障态唯一使用氧化朱红（Light `#B93827` / Dark `#EE7262`）。

## 4. App Icon 概念：Optical Aperture Collimator（光学准直收束口）

- **单色剪影测试优先**：左右对称的 104° 光学青收束弧（顶部 12 点与底部 6 点双向敞开，彻底规避电源键视觉混淆，并以格式塔闭合读出 Omni 的 O 形光学光圈）+ 居中贯通下坠的精密雾银箭矢（象征 Fetch 捕获入库）。
- **相较旧版改进**：消除旧版箭头生硬刺穿底环造成的尖角碎裂与头轻脚重，采用 Apple 连续超椭圆（Continuous Squircle）外壳、阳极氧化深岩灰底板、内凹铣削光学镜腔与统一 12 点顶光高光倒角，与 App 内部 Visual DNA 严格统一。
- **尺寸光学调校**：`16px/32px` 自动收紧外边距、略微加粗笔画并移除微刻度；`256px–1024px` 呈现内凹镜腔、左右 10 刻度光学标线与顶缘金属倒角高光。

## 5. SwiftUI 流畅度工程预算

1. **零布局抖动进度条**：进度填充以 GPU `scaleEffect(x:anchor:.leading)` 驱动，避免 10 Hz 更新触发主线程布局重排。
2. **ImageIO 后台降采样 + `NSCache` 缩略图**：替换会反复闪烁重载的 `AsyncImage`，命中缓存首帧同步绘制，大尺寸封面后台解码至 `240px` 缩略图尺寸。
3. **行级 `Equatable` + 局部 Hover 状态**：每行独立管理悬停态，进度刷新只重绘变更行，滚动长列表（`LazyVStack`）保持稳定高帧率。
4. **物理阻尼动效与减动效适配**：按下 `120ms` 零延迟微缩 `0.97`；面板与过滤器切换采用临界阻尼弹簧（无廉价过冲）；尊重 `accessibilityReduceMotion` 与 `accessibilityReduceTransparency`。
